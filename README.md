## Structure d'un exercice

Chaque exercice suit la même démarche :
1. **Dispositif expérimental** — nature des variables (qualitatives/quantitatives)
2. **Choix du test** — justification statistique
3. **Mise en place du test dans STATISTICA** — menu par menu
4. **Résultats** — tableaux de sortie et interprétation
